# Madhav Dalsaniya - Full-Stack Developer Portfolio

This is a premium, modern, fully responsive personal portfolio website for Full-Stack Developer **Madhav Dalsaniya**. The design features a professional dark tech aesthetic with glassmorphism layouts, neon glowing accents, soft micro-animations, and full-screen layouts that scale seamlessly from 320px mobile screens to large desktop monitors.

## 🚀 Features

- **Responsive Grid & Flexbox Layout**: Automatically adapts to a single-column stack on tablets and mobile screens.
- **Modern Dark Tech Palette**: Deep slate background with glowing neon Violet and Cyan highlights.
- **Glassmorphism Panels**: Cards featuring blurred backdrops, glowing borders, and smooth scaling transitions.
- **Interactive States**: Smooth hover states, float animations, sliding navigation highlights, and interactive menu toggling.
- **Custom Project Visuals**: Custom generated illustration assets for the showcase cards.
- **Instant Actions**: Email and phone click-to-call/mail actions, resume download CTA, and an interactive contact form.

## 💻 How to Run

Since this is a client-side frontend project using native HTML and CSS, you can run it instantly:

1. **Locally**:
   - Double-click the `index.html` file in your file explorer, OR
   - Right-click `index.html` and choose **Open with** your preferred browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari, etc.).
2. **Using a Dev Server (Recommended for development)**:
   - If using VS Code, install the "Live Server" extension, open the directory, and click **Go Live** at the bottom-right.
   - Using Node.js, run `npx serve` in the workspace directory.
